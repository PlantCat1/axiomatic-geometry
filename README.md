# Axiomatic Geometry

An axiomatic formalizaion of plane geometry with a focus on minimalism and axiomatic independce. Real numbers, coordinate grids, or measure functions are not used. Instead, derived constructs are defined strictly using point sets and primitive relations.

This formalization is built on a single set of points $\mathbf{P}$ and two primative relations acting upon that set: ternary betweeness $\mathcal{B}(A,B,C)$, and quaternary segment congruence $AB \cong CD$. From this, geometric figures and relations are defined as sets of points using these relations.

This project is heavily inspired by Tarski's Geometry. However, a set-theoretic approach is taken rather than the creation of a pure first-order logic system. As a result, this system constructs linear notions, angles, and half-planes as first-class set-theoretic objects. Derived relations such as parallelism are also defined via set operations, allowing for them to act as equivalence relations. Differences in axioms are also present.
